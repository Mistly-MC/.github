## Repositories

| | |
|---|---|
| [**Mistly-Launcher**](https://github.com/Mistly-MC/Mistly-Launcher) | The launcher for Windows and Linux, written in Rust with a [Slint](https://slint.dev) interface |
| [**Mistly-Client**](https://github.com/Mistly-MC/Mistly-Client) | Mistly Client, the optional in-game Fabric mod: HUD, zoom, wardrobe and cosmetics |
| [**Mistly-Web**](https://github.com/Mistly-MC/Mistly-Web) | The [mistly.cc](https://mistly.cc/) website, its docs and its shop |
